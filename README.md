# Rouh Website

Premium Arabic RTL landing website for **Rouh by Aseel Omar**.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Reusable component architecture
- Arabic RTL layout

## Content Updates

Most editable content, media paths, payment placeholders, video placeholders, and contact links live in:

```txt
data/siteContent.ts
```

Replace assumed media inside:

```txt
public/images
public/docs
```

The free booklet path is expected at:

```txt
public/docs/free-booklet.pdf
```

## Development

npm install
npm run dev
